# Financely Pro - Personal Finance Management System

**Financely Pro** is a modern, lightweight, and independent web-based personal finance management system. Built with simplicity and flexibility in mind, it allows users to manage assets, track expenses, monitor debts, and sync data seamlessly with Google Sheets.

![Tech Stack](https://img.shields.io/badge/Tech-HTML%20%7C%20Tailwind%20CSS%20%7C%20JS-orange)

## 🚀 Features

### 📊 Dashboard & Analytics
- **Net Worth Overview**: Real-time calculation of Total Assets, Total Debts, and Net Worth.
- **Dynamic Widgets**:
  - **Monthly Summary**: Visual comparison of Income vs. Expenses.
  - **Daily Average**: Track your average spending per day.
  - **Payment Planner**: Monitor upcoming credit installments and due dates.
- **7-Day Cash Requirement**: Automatic estimation of funds needed for upcoming bills within the next week.

### 💳 Account Management
- Support for multiple account types: **Bank Accounts**, **E-Wallets**, and **Credit Lines**.
- **Credit & Installments**: Manage complex debt structures with automated installment tracking and tenor management.

### 📝 Transaction Tracking
- **Income & Expense Logging**: Record daily transactions with categories.
- **Debt Payments**: Dedicated flow for paying installments with support for admin fees and additional charges.
- **Balance Transfers**: Move funds between accounts easily.
- **Advanced Filtering**: Search and filter history by type, account, and date range.

### ☁️ Cloud Sync (Google Sheets)
- **Delta Sync Technology**: Intelligent synchronization that only updates changes.
- **Google Apps Script Integration**: Use Google Sheets as a secure, private cloud database.
- **Local Persistence**: Works offline using Browser Local Storage.

### 📱 Responsive UI
- Modern aesthetic using **Tailwind CSS** and **Plus Jakarta Sans** font.
- Dedicated mobile navigation and floating action menu for a native app-like experience.

## 🛠 Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript.
- **Styling**: Tailwind CSS (via CDN).
- **Icons**: Heroicons (SVG).
- **Backend/Cloud**: Google Apps Script (Web App).

## 📖 How to Use

1. **Local Access**: Simply open `index.html` in any modern web browser.
2. **Setup Accounts**: Add your bank accounts, e-wallets, or credit cards in the Dashboard tab.
3. **Record Transactions**: Use the "Catat Transaksi" button to start logging your finances.
4. **Cloud Backup (Optional)**:
   - Go to the **Google Sheets Sync** menu.
   - Follow the instructions to deploy the provided Google Apps Script.
   - Paste your Web App URL to enable cloud synchronization.

## 🔒 Privacy
Financely Pro is designed with privacy in mind. Your data stays in your browser's local storage and your personal Google Spreadsheet. No third-party servers are involved in handling your financial data.
